Fix Orvos C90 compliance and document known limitations

This commit fixes all C90 "declaration-after-statement" warnings in the
Orvos columnar table access method code, ensuring strict C90 compliance
as required by PostgreSQL. Also documents the VACUUM delta UPDATE bug
as a known limitation.

C90 Compliance Fixes (6 files, 13 warnings):
- PostgreSQL requires strict C90: all variable declarations must appear
  before any statements in a code block
- Fixed "mixing declarations and code" warnings by moving all variable
  declarations to the beginning of their respective blocks
- All (void) statements for unused parameters now appear after declarations
