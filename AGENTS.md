# Project guidance

## HOT selective index update (HOT/SIU) terminology

When writing or editing code comments, commit messages, and docs for the
HOT-indexed / selective-index-update work, do NOT use the phrases "PHOT",
"PHOT-faithful", or any "WARM"/"WARM-style" wording. Write plain, informative
comments instead.

Preferred terms (use these):
- "HOT-updated"
- "HOT-selective-updated"
- "HOT/SIU"
- "HOT selective index update"
- "Heap-only Tuple with selectively updated indexes"

This applies to new comments and to rewriting any existing comment that uses
the disallowed phrasing.
